📧 Mailer API - Netlify Functions

📚 API Endpoints

Health Check: GET /.netlify/functions/health-check

Send Email: POST /.netlify/functions/send-email

📝 Request Body for Send Email:

{
  "to": "recipient@example.com",
  "subject": "Email Subject",
  "htmlContent": "<h1>Hello</h1><p>Content</p>",
  "from": "sender@example.com" // optional
}
